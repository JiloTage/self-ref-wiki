対角線論法

最終更新: 2026-03-23
対角線論法（diagonalization / diagonal argument）とは、ある集合が列挙不可能であることを、仮定された列挙の「対角線」上の要素を反転させることで証明する手法である。1891年にゲオルク・カントールが実数の非可算性の証明に用いて以来、ゲーデルの不完全性定理、チューリングの停止問題の決定不能性証明など、自己参照に基づく数学・計算機科学の根本的な不可能性定理のほぼすべてに共通する証明技法である。

基本的なアイデア

対角線論法の基本構造は以下の通りである：

  1. 仮定：ある集合のすべての要素を列挙できると仮定する
  2. 対角線の構成：その列挙を表にしたとき、対角線上の要素（第 n 番目の要素の第 n 番目の成分）を取り出す
  3. 反転：対角線上の各要素を「反転」（否定、変更）した新しい要素を構成する
  4. 矛盾：この新しい要素は列挙のどの要素とも異なる（第 n 番目の要素とは少なくとも第 n 成分で異なる）ため、列挙の完全性に矛盾する
図1: カントールの対角線論法 — 青が対角線要素、赤が反転された新要素 d*

カントールの定理（1891年）

カントールは対角線論法を用いて、実数の集合は自然数の集合より真に大きい（非可算である）ことを証明した。[0,1] 区間の実数をすべて列挙できると仮定し、各実数を二進小数展開で表す。対角線上の第 n 桁を反転させた新しい実数は列挙に含まれないため矛盾が導かれる。

この証明は、すべての自然数に関する操作（列挙）が自然数では「捉えきれない」対象を生み出すという点で、本質的に自己参照的である。

ゲーデルの不完全性定理における対角化

ゲーデルは、形式体系の証明可能な命題をすべて列挙し、対角線論法を適用することで「この命題は証明不可能である」という自己言及命題を構成した。これが対角線補題（diagonal lemma / fixed-point lemma）であり、不完全性定理の核心をなす。

ゲーデル数の仕組みにより、形式的命題が自然数として表現され、体系が自身の命題について語ることが可能になる。対角線論法はこの「自己言及可能性」を体系的に利用する。

チューリングの停止問題

アラン・チューリングは1936年に対角線論法を用いて、任意のプログラムが停止するかどうかを判定する一般的なアルゴリズムは存在しないことを証明した。

停止判定器 H(P, I) が存在すると仮定し、D(P) = if H(P,P) then loop else halt というプログラムを構成する。D(D) の挙動は矛盾を導く——これはまさに対角線論法の構造である。ここで H(P,P)（プログラムに自身を入力として与える）が対角線要素に対応する。

クワインとの関係

クワインの構成もまた対角線論法の一形態である。プログラムが自身のソースコードを取得する仕組みは、対角線補題の構成的証明と同型である。不動点コンビネータはこの対角化を関数レベルで実現するものと見なせる。

一般化と応用

対角線論法は以下の定理の証明にも本質的に用いられる：

  • ラッセルのパラドックス：「自分自身を含まない集合の集合」——集合論における対角化
  • タルスキの定理：形式体系は自身の真理述語を定義できない
  • ライスの定理：プログラムの非自明な意味的性質は決定不能
  • カリーのパラドックス：自己参照的条件文による矛盾

これらはすべて、あるシステムが自身を完全に記述・制御しようとする試みが本質的に不可能であることを示しており、自己参照の根源的な限界を明らかにする。
