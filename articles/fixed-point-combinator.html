不動点コンビネータ

最終更新: 2026-03-23
不動点コンビネータ（fixed-point combinator）とは、任意の関数 f に対してその不動点 x = f(x) を計算する高階関数である。Self-Reference Engineの理論的中核をなす概念であり、ラムダ計算においては再帰の唯一の実現手段である。最も有名な不動点コンビネータはハスケル・カリーが発見したYコンビネータである。

概要

関数 f の不動点とは、f(x) = x を満たす値 x のことである。不動点コンビネータ fix は、任意の関数 f を受け取り、fix(f) = f(fix(f)) を満たす値を返す。

型なしラムダ計算には再帰を直接表現する構文がないため、不動点コンビネータが再帰関数を定義する唯一の方法となる。関数が「自分自身を呼び出す」のではなく、不動点コンビネータが関数に「自身の不動点」を供給することで再帰が実現される。

図1: 不動点コンビネータの動作 — fix が関数 f を受け取り、f(x) = x を満たす x を返す

Yコンビネータ

最も有名な不動点コンビネータはYコンビネータであり、以下のように定義される：

Y = λf. (λx. f (x x)) (λx. f (x x))

任意の関数 g に対して：

Y g = (λx. g (x x)) (λx. g (x x))
    = g ((λx. g (x x)) (λx. g (x x)))
    = g (Y g)

すなわち Y g = g (Y g) が成り立ち、Y g は g の不動点である。

Yコンビネータは遅延評価（正規順序）を前提としている。正格評価の言語では Y g の計算が無限ループに陥るため、Zコンビネータを使用する。

Zコンビネータ

ZコンビネータはYコンビネータの正格評価版であり、η展開（eta-expansion）を施して評価の遅延を実現する：

Z = λf. (λx. f (λv. x x v)) (λx. f (λv. x x v))

λv. x x v によって x x の評価が遅延され、引数 v が実際に供給されるまで展開が保留される。このため、Python や JavaScript などの正格評価言語でも不動点コンビネータを用いた再帰が実現できる。

Θコンビネータ

Θコンビネータ（チューリングの不動点コンビネータ）はアラン・チューリングが発見したもので、以下のように定義される：

Θ = (λx. λy. y (x x y)) (λx. λy. y (x x y))

Yコンビネータと異なり、Θはf の不動点を直接計算する（β簡約1ステップで Θ f = f (Θ f) が得られる）。

ラムダ計算における不動点

型なしラムダ計算では、すべての項に不動点が存在する。これは λx. x x のような自己適用が無制限に許されることによる。実際、不動点コンビネータは無限に多く存在し、Yコンビネータ、Θコンビネータはそのうちの二つに過ぎない。

不動点コンビネータの存在は、型なしラムダ計算がチューリング完全であることの鍵であり、同時に強正規化性（すべての項が正規形を持つ性質）を持たない理由でもある。

型付きラムダ計算と不動点

単純型付きラムダ計算では、λx. x x のような自己適用に型を付けることができず、Yコンビネータは型付けできない。これは単純型付きラムダ計算が強正規化性を持つことに対応する——すべての計算が停止するため、無限ループ（＝不動点コンビネータの展開）は不可能である。

再帰を許すために、実用的な型付き言語は以下のような方法を採る：

  • 再帰型（recursive types）：μ型を導入し、μα. α → α のような型を許容する
  • fix プリミティブ：fix : (α → α) → α を組み込みで提供する（Haskell、OCaml等）
  • 一般再帰：let rec 構文として直接サポートする

型理論（System F、依存型理論など）における不動点の扱いは、体系の表現力と停止性のトレードオフに直結する重要な問題である。

タルスキの不動点定理

タルスキの不動点定理（1955年）は、完備束上の単調関数が必ず不動点を持つことを保証する。計算機科学ではデノテーショナル意味論（表示的意味論）において中心的な役割を果たし、再帰的プログラムの意味を最小不動点として定義する理論的基盤を提供する。

クリーネの再帰定理

クリーネの再帰定理は、不動点コンビネータの計算可能性理論版である。任意の計算可能関数 f に対し、φe = φf(e) を満たすインデックス e が存在する。これはクワインの存在保証や、ゲーデルの不完全性定理における対角線補題と密接に関連する。

圏論的不動点

圏論では、不動点は自己関手（endofunctor）の代数として定式化される。関手 F の初期代数 (μF, in) はランベックの補題により F(μF) ≅ μF を満たす——すなわち F の不動点である。帰納的データ型（リスト、木など）の理論的基盤を提供する。

プログラミングにおける応用

不動点コンビネータは理論的に重要であるだけでなく、実際のプログラミングでも応用される：

  • 無名再帰：名前を持たないラムダ式で再帰を実現する
  • メモ化再帰：不動点コンビネータをメモ化関数で包むことで、再帰関数に透過的にメモ化を追加できる
  • オープン再帰：オブジェクト指向における self / this のメカニズムは不動点の適用と見なせる
  • トランポリン：スタックオーバーフローを防ぐ反復的不動点計算
