ラムダ計算

最終更新: 2026-03-23
ラムダ計算（λ-calculus）は、1930年代にアロンゾ・チャーチが考案した形式体系であり、関数の定義・適用・抽象化のみによって計算を表現する。チューリングマシンと同等の計算能力を持ち、関数型プログラミングの理論的基盤をなす。不動点コンビネータ（Yコンビネータ）の母体であり、自己参照を自己適用（λx. x x）という形で最も純粋に表現する計算体系である。

構文

ラムダ計算の項（ラムダ項）は以下の3つの構成要素のみから成る：

  • 変数：x, y, z, …
  • 抽象化（関数定義）：λx. M — 変数 x を束縛し本体 M を持つ関数
  • 適用（関数呼び出し）：M N — 関数 M に引数 N を適用

この極めて単純な構文から、自然数、論理値、データ構造、制御フロー、そして再帰のすべてが表現可能である。

簡約規則

ラムダ計算の計算は以下の規則に従う：

α変換（α-conversion）

束縛変数の名前を変更する。λx. M ≡α λy. M[x:=y]（y が M 中で自由でない場合）。変数名は本質的でないことを保証する。

β簡約（β-reduction）

関数適用の計算規則。(λx. M) N →β M[x:=N]。これがラムダ計算における唯一の本質的な計算ステップである。

η変換（η-conversion）

関数の外延的等価性。λx. M x ≡η M（x が M 中で自由でない場合）。

自己適用

ラムダ計算における自己参照の最も直接的な表現は自己適用——関数を自分自身に適用すること——である：

ω = λx. x x
Ω = ω ω = (λx. x x)(λx. x x)

Ω は自分自身にβ簡約される（Ω →β Ω）。これは停止しない計算を表し、ラムダ計算が停止問題を含意することの直接的な証拠でもある。

図1: Ω コンビネータ — 自己適用による無限ループの最小表現

Yコンビネータと不動点

不動点コンビネータの最も有名な形であるYコンビネータは、自己適用を制御された形で利用して再帰を実現する：

Y = λf. (λx. f (x x))(λx. f (x x))

任意の関数 f に対して Y f = f (Y f) が成り立つ。つまり Y f は f の不動点である。これにより、ラムダ計算のように名前付き定義を持たない体系でも再帰的関数を定義できる。

この構造は対角線論法と同型であり、クワインの構成原理とも直結する。

チャーチ・エンコーディング

ラムダ計算では純粋な関数のみでデータを表現する：

  • チャーチ数：0 = λf.λx. x、1 = λf.λx. f x、n = λf.λx. fn x
  • 論理値：true = λa.λb. a、false = λa.λb. b
  • ペア：pair = λa.λb.λf. f a b

チャーチ数 n は「関数を n 回適用する」という操作そのものを関数として捉えるものであり、データと操作の区別を消去するという点で、自己参照エンジンの原理と深く通じる。

チャーチ＝チューリングのテーゼ

1936年、チャーチはラムダ計算で計算不可能な関数の存在を証明し、同時期にチューリングがチューリングマシンで同等の結果を示した。両者の計算能力が等価であることが証明され、チャーチ＝チューリングのテーゼ——「実効的に計算可能な関数」の概念はこれらの形式化と一致する——が提唱された。

型付きラムダ計算

型なしラムダ計算では自己適用 ω = λx. x x が自由に書けるが、単純型付きラムダ計算では x x に型を付けることができず、自己適用が禁止される。これにより Ω のような発散する項が排除され、すべての計算が停止する（強正規化定理）。

しかし、これは同時に再帰を直接表現する能力を失うことを意味する。型理論はこの緊張——自己参照の表現力と体系の安全性のトレードオフ——を精密に扱う分野である。

影響

  • Lisp（1958年）：ジョン・マッカーシーがラムダ計算を基に設計した最初の関数型言語
  • ML / Haskell / OCaml：型付きラムダ計算を基盤とする現代の関数型言語群
  • カリー＝ハワード対応：型付きラムダ計算の型が論理の命題に、項が証明に対応するという同型性
  • GEB：ホフスタッターがラムダ計算と自己参照の関係を一般読者に紹介
